# AMC v1.2.3

This release resolves Gemini API authentication issues and provides automatic credential cleanup.

- **Gemini Authentication**:
  - Automatically strips accidental `Bearer ` prefixes from pasted API keys.
  - Adds the official `x-goog-api-key` header to Gemini streaming requests.
  - Adds native support for OAuth 2.0 access tokens (`ya29...`) via `Authorization: Bearer`.
  - Emits clear, actionable error messages for `ACCESS_TOKEN_TYPE_UNSUPPORTED` directing users to Google AI Studio.
  - Validates missing keys before sending network requests to prevent confusing 401/403 errors.

## Downloads

- `AMC-1.2.3-release.apk`: signed release build, with debugging disabled.
- `AMC-1.2.3-debug.apk`: development build with debugging enabled.
- Matching ZIP files contain the same APKs.
- `SHA256SUMS.txt` contains download checksums.

Release APK availability requires the configured private signing secrets.
Debug and release builds use different signing identities; Android may reject switching variants as an in-place update. Export chats before changing installations.

Update the Termux bridge using the setup instructions in the README to apply bridge fixes. Installing the APK alone does not update Termux files.
