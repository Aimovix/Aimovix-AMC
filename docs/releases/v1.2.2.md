# AMC v1.2.2

This release delivers comprehensive bugfixes across LLM protocols, session persistence, process stability, command security filtering, and full English localization.

- **Security Hardening**: Fortified `CommandSecurityFilter` against shell obfuscation, `$IFS` expansions, zero-width characters, argument reordering, and dangerous filesystem path variants.
- **LLM Protocol Fixes**:
  - Maintained tool call IDs correctly for OpenAI/Groq endpoints.
  - Implemented native Claude tool calling with `tool_result` and `tool_use_id`.
  - Added support for Gemini camera vision input sequences and preserved `thoughtSignature` metadata.
  - Filtered internal `SYSTEM` messages from provider serialization to prevent empty payload errors.
- **Session & UI Persistence**:
  - Fixed chat title erasure on message save (`touchSession`).
  - Persisted live streaming tool states and terminal cards across app restarts and view switching.
  - Offloaded image decoding to background threads with automatic downsampling to prevent OOM.
  - Switched chat export to Storage Access Framework (`ACTION_CREATE_DOCUMENT`) so exports persist across app reinstalls.
- **Bridge & Process Stability**:
  - Isolated connection generation tracking in `TermuxBridgeClient` to discard stale callbacks.
  - Active heartbeat ping-pong watchdog with 5-second timeout.
  - Separated ring-buffered `stdout` and `stderr` streams capped to prevent memory exhaustion.
  - Atomic `.part` downloads with `--fail` for local model downloads.
- **System Permissions & Android 14/15**:
  - Added package visibility `<queries>` for `com.termux` and speech recognition services.
  - Added timeout handling for Android 14/15 foreground dataSync services.
  - Added runtime prompt for `POST_NOTIFICATIONS`.
- **Localization**: 100% English UI, error messages, and documentation.

## Downloads

- `AMC-1.2.2-release.apk`: signed release build, with debugging disabled.
- `AMC-1.2.2-debug.apk`: development build with debugging enabled.
- Matching ZIP files contain the same APKs.
- `SHA256SUMS.txt` contains download checksums.

Release APK availability requires the configured private signing secrets.
Debug and release builds use different signing identities; Android may reject switching variants as an in-place update. Export chats before changing installations.

Update the Termux bridge using the setup instructions in the README to apply bridge fixes. Installing the APK alone does not update Termux files.
