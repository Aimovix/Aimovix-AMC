# AMC v1.2.1

This release includes the latest bridge, installer, and AI streaming fixes.

- Allow graceful bridge shutdown to finish and recognize exited processes.
- Preserve the running bridge PID when a duplicate start fails.
- Keep installed bridge files intact when an installer download fails.
- Explain AI provider DNS failures and distinguish them from the local Termux connection.
- Respect cancellation during AI stream processing.
- Clean up output buffers when commands cannot be sent to Termux.

## Downloads

- `AMC-1.2.1-release.apk`: signed release build, with debugging disabled.
- `AMC-1.2.1-debug.apk`: development build with debugging enabled.
- Matching ZIP files contain the same APKs.
- `SHA256SUMS.txt` contains download checksums.

Release APK availability requires the configured private signing secrets.
Debug and release builds use different signing identities; Android may reject switching variants as an in-place update. Export chats before changing installations.

Update the Termux bridge using the setup instructions in the README to apply bridge fixes. Installing the APK alone does not update Termux files.

Android unit tests, bridge integration tests, shell syntax checks, and APK signature checks run before publication. Physical-device testing has not been performed. Device internet or DNS problems still require a working network connection.
