# AMC v1.2.4

This release addresses 37 architectural, stability, protocol, and security findings across the autonomous agent engine, LLM clients, Termux bridge, and Android application.

## Key Changes & Improvements

### P1 – Critical & Stability Fixes
- **Provider Switching**: Fixed synchronization in settings when switching primary and fallback providers, ensuring keys, models, and base URLs are updated and persisted cleanly.
- **Multi-Tool Approvals**: Added full multi-tool approval UI and execution tracking matching specific tool call IDs.
- **Room & JSON Tool Calls Persistence**: Preserved multi-tool arrays across SQLite entity mapping and JSON session exports with backward compatibility.
- **Stop & SQLite Foreign Key Races**: Fixed session deletion foreign key race conditions by strictly coordinating job cancellations (`cancelAndJoin`) prior to database removal.
- **LLM Call Cancellation**: Replaced OkHttp callback completion with `suspendCancellableCoroutine` without leaking threads or violating Kotlin Flow invariants.
- **Stop Coordination**: Set synchronous stopping flags in `emergencyStop` to immediately reject subsequent commands.
- **Aborted Tool Call Recovery**: Synthesized `ToolResult` error entries on user cancel or loop protection stop to prevent orphaned assistant turns.
- **Gemini Protocol Hardening**: Serialized `thoughtSignature` at the part level and grouped function responses in a single user turn.

### P2 – Agent Engine & Context Safety
- **Loop Protection**: Terminated iteration loops immediately without triggering an extra LLM turn.
- **Context Pruning**: Budgeted user prompt tokens first and preserved assistant-tool pair integrity when pruning historical context turns.
- **Task Start Safety**: Exposed `isInitialized` StateFlow and only cleared the chat input field when a task is accepted.
- **Session Switching**: Cleared transient message state and cancelled previous active collectors before loading the target session.
- **Lifecycle Cleanup**: Added `close()` to `AutonomousAgentEngine` and invoked it in `MainViewModel.onCleared()`.
- **Stream Completion Checks**: Enforced strict `[DONE]` checking and validation for OpenAI and Claude streams.
- **Tool Arguments**: Enforced strict validation of LLM tool call JSON arguments.
- **Vision Timing**: Appended pending image observations strictly after completing the tool execution turn.
- **Model Directory**: Updated Claude default to `claude-3-7-sonnet-latest` and added latest model options.

### P3 – Termux Bridge, Terminal, UI & Automation
- **Bridge Reconnects**: Rejected stale pending executions on bridge reconnects and serialized connection attempts.
- **WebSocket Heartbeat**: Implemented continuous 15-second ping/pong heartbeats to catch silent connection drops.
- **HeadTailBuffer**: Capped streaming command outputs at 100 KB head and 150 KB tail with omission notices.
- **Terminal State**: Decoupled terminal commands across tab navigations via `TerminalViewModel` and bounded history to 100,000 characters.
- **Image Decoding**: Offloaded Base64 chat image decoding to `Dispatchers.IO` via `produceState`.
- **Artifact Path Quotes**: Tokenized quoted shell command arguments to support file paths with whitespace.
- **Artifact Viewer**: Added retry handling on file loading failures.
- **Session Export**: Preserved pending export session and format across Activity recreation using `rememberSaveable`.
- **Crontab Protection**: Gated "Sync crontab" until crontab content is loaded, preventing accidental crontab erasure.
- **WorkManager Automation**: Allowed `RiskLevel.LOW` tasks to run unattended and added bridge connection timeout retries.
- **Local Model Manager**: Validated GGUF file size (>= 100 MB) and magic bytes, and updated existing `llama.cpp` check.
- **AMC Process Ownership**: Protected against PID reuse in `amc` via `/proc/$pid/cmdline` validation.
- **Settings Migration**: Preserved custom URLs and models during migration.

## Downloads

- `AMC-1.2.4-release.apk`: signed release build, with debugging disabled.
- `AMC-1.2.4-debug.apk`: development build with debugging enabled.
- Matching ZIP files contain the same APKs.
- `SHA256SUMS.txt` contains download checksums.

Release APK availability requires the configured private signing secrets.
Debug and release builds use different signing identities; Android may reject switching variants as an in-place update. Export chats before changing installations.

Update the Termux bridge using the setup instructions in the README to apply bridge fixes. Installing the APK alone does not update Termux files.
