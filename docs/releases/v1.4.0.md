# AMC v1.4.0 — Remote channel and sub-agents

AMC moves closer to self-hosted personal agents such as OpenClaw and OpenCrabs, but everything still runs on the phone itself: no server, no extra computer.

## Telegram channel (remote control)

- **Talk to your phone's agent from anywhere:** create a bot with @BotFather, paste its token in **Settings → Channels**, switch the channel on and pair your Telegram account with a one-time code. The phone long-polls Telegram, so no server, port forwarding or webhook is needed.
- **Private by design:** only paired accounts in private chats reach the agent. Pairing codes are single-use, valid for 15 minutes and invalidated after 5 wrong attempts. Strangers get a short pairing hint at most every 10 minutes and never reach the agent. A notification on the phone reports every newly paired account.
- **Approvals as buttons:** actions that need approval arrive as ✅/❌ buttons in the chat; no answer within 10 minutes counts as rejected. Actions that affect other people or cost money (SMS, calls, camera, microphone, contacts, messages) are marked and still need your explicit confirmation.
- **Persistent conversations:** each Telegram chat continues its own AMC chat session (visible in the app's session drawer). `/new` starts a fresh one, `/stop` stops the running task, `/status` shows model, security mode and bridge state, `/unpair` disconnects the account.
- **Steering and photos:** messages sent while the agent works are added to the running task. Photos (with or without a caption) are passed to vision-capable models.
- **Files back to you:** the new `send_file` tool uploads photos, screenshots, PDFs and reports into the chat.
- **Runs in the background:** a `specialUse` foreground service keeps the channel connected (no daily time limit), holds a wake lock only while a task runs, and restarts after reboot or app update when the channel is enabled.

## Agent

- **Sub-agents (`delegate_task`):** the agent can hand a self-contained sub-task (research, comparing many files or pages, trying an approach) to a sub-agent with a fresh context. The sub-agent's steps stream into the tool card, its approvals are forwarded to you, its token use is added to the session, and it cannot delegate further.
- **Web search (`web_search`):** keyless search through DuckDuckGo; the agent reads promising results with `web_fetch`.
- **Conversation recall (`search_history`):** finds what you discussed in earlier chats when it is not in long-term memory.
- **Persona (SOUL.md):** **Settings → Autonomy → Persona & standing instructions** defines who the agent is and how it should work for you. It applies to every chat, Telegram conversation, background run and sub-agent, and never overrides the security and legal rules.
- **Installed skills in the prompt:** at the start of a run the agent sees every skill in `~/.amc/skills/` with its description. Both `<name>.md` and `<name>/SKILL.md` (Agent Skills / OpenClaw format with `name:` and `description:` front matter) are supported, and new skills are written in the folder format.
- **Voice input in your language:** speech recognition now uses the device language instead of always English.

## Under the hood

- One `runHeadless` entry point drives background runs, channel conversations and sub-agents; approval handling is unified across interactive, unattended, remote and sub-agent runs.
- Providers can receive a reduced tool list (used to keep `delegate_task` away from sub-agents).
- 33 new unit tests: Telegram gateway (pairing, strangers, approvals via callbacks, timeouts, steering, `/stop`, `/new`, `/unpair`), complete headless runs against a fake model server (remote approvals, sub-agents, forwarded approvals, persona), web search parsing, skills index, Telegram formatting and the new tools' risk levels.
