# AMC v1.3.0 — Autonomous agent

AMC now works as a fully autonomous personal agent on the phone: it plans, acts, remembers, and follows up on its own, while sensitive actions still need your approval.

## Autonomy

- **Autonomous mode (new default preset):** reading, writing files, running scripts, installing packages and downloading run without prompts. SMS, calls, camera, location, clipboard, deleting files and killing processes still ask first. Existing installations keep the preset they had selected; the old *Default* preset is now named *Supervised*.
- **New tools:** `read_file`, `write_file`, `web_fetch` (native HTTP, HTML to text), `remember` / `forget`, `update_plan`, `notify_user`, `schedule_task`, `list_scheduled_tasks`, `cancel_scheduled_task`, alongside `execute_command` (now with an optional per-command timeout up to 30 minutes). One tool registry generates the schemas for Gemini, OpenAI-compatible providers and Claude.
- **Long-term memory:** facts the agent saves are included in every conversation; edit or clear them in **Settings → Autonomy**.
- **Scheduled agent tasks:** the agent can schedule itself for one-time or recurring background runs. Every run gets its own chat session and ends with a notification. Background runs never approve themselves.
- **Heartbeat:** optional periodic check-in against your checklist; it only notifies you when something needs attention.
- **Skills:** the installer creates `~/.amc/skills/`; the agent reads and writes reusable how-to files there.
- **Live plan and steering:** a progress panel shows the plan and step counter, and you can send further instructions while the agent works.
- **Configurable step budget:** 5–100 steps per task (default 30, previously a fixed 15). Repeated failures trigger a "rethink your approach" hint before the run stops, and loop protection warns once before it stops.
- **Replies in your language:** the agent answers in the language you write in.

## Legal safeguards

- **Consent on first launch:** terms of use, disclaimer and privacy notice (English and German) must be accepted before the app or any background run can be used; reread them in **Settings → Legal & privacy**.
- **Always-confirm actions:** sending SMS, calls, reading messages, contacts or call logs, camera photos and microphone recordings always ask for confirmation, in every mode including Turbo, and are never run in the background.
- **Lawful-use rules** in the agent's system prompt.
- New documents in `docs/legal/`: terms, privacy notice, third-party notices, imprint template.

## Fixes

- Gemini: tool results now report the name of the tool that produced them (previously always `execute_command`).
- Context window: the history sent to the model always starts with a user message, every tool call has exactly one result (missing results after a crash are filled in), stray tool results are dropped, and only the three latest images are replayed. The window is larger (40 messages / 120k characters).
- OpenAI-compatible streaming: tool call ids and names repeated in every chunk by some servers are no longer concatenated; tools without parameters are accepted.
- OpenAI reasoning models (o-series, GPT-5) no longer receive an unsupported `temperature`.
- Claude: the system prompt and tools are prompt-cached, `max_tokens` raised to 16,000, and `refusal` stop reasons are reported clearly.
- Updated model suggestions (Claude Opus 5.5 default for Anthropic; current Gemini, OpenAI, Groq and OpenRouter IDs) and cost estimates.
- Database writes from the agent can no longer crash the app when they fail.
