# AMC v1.2.0

- English app interface, prompts, notifications, exports, setup scripts, and documentation.
- Authenticated device-local Termux bridge.
- Responsive emergency stop, server-side timeouts, and disconnect cleanup.
- Conservative command approval and encrypted credential storage without plaintext fallback.

## Downloads

- `AMC-1.2.0-debug.apk`: installable development build.
- `AMC-1.2.0-debug.zip`: the same debug APK in a ZIP archive.
- `AMC-1.2.0-release.apk`: signed, non-debuggable release build, available after private signing is configured.
- `AMC-1.2.0-release.zip`: the same signed release APK in a ZIP archive.
- `SHA256SUMS.txt`: checksums for available downloads.

The automatically generated **Source code** ZIP is the repository source, not an installable app.

## Installation and pairing

Debug and release builds have different signing identities. Earlier versions used an exposed key. Export your chats before changing installations; Android may reject an in-place update when signatures differ. No existing installation is removed automatically.

Run the current Termux setup script, then run `amc token` and enter the token in **AMC → Setup**. Authentication is required.

Automated Android and bridge tests run before publication. Physical-device testing has not been performed for this release.
