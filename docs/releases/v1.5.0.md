# AMC v1.5.0 — Calmer design

The interface now looks like a tool, not a terminal demo. Everything on screen has a job, nothing decorates for its own sake, and motion only explains what changed.

## Look

- **Tone instead of borders:** the dark palette uses three surface steps. Most of the 1 dp outlines and glowing accents are gone.
- **One type family:** the whole app uses the system sans-serif with a small scale. Nothing is smaller than 11 sp. Monospace is reserved for commands and terminal output.
- **One corner-radius scale** across cards, chips, buttons and bubbles.
- **Accent used sparingly:** the accent marks the primary action and "connected". Risk is shown in red and amber, and only when it matters.
- **No decorative emoji:** removed from toasts and labels. System notes keep their wording and drop the decorative symbol in front.

## Chat

- **Agent replies are plain text.** No bubble and no repeated "AMC Agent" label on every answer. Your messages sit in a quiet bubble on the right.
- **Tool activity is one line:** status, command and a chevron. It stays open while the command runs and when it failed, so errors are visible. After success it folds away. Tap the line to open or close it.
- **"Thinking…"** replaces an empty bubble while the model answers.
- **Connection banner** only appears when Termux is not reachable, with one sentence and the actions that can fix it (Reconnect, Boost).
- **Stop** is written as "Stop", in the same place and colour as before.
- **Empty state:** a plain headline and one sentence instead of a large icon.

## Approvals

- **"Run" and "Don't run" have the same size, shape and surface.** Their labels say exactly what happens.
- The full command is always shown and can be scrolled.
- The risk is stated in words. "Run" turns red only for high-risk actions.
- Approving and rejecting give a light haptic confirmation.

## Motion

- Short springs for size and rotation changes, a fade-and-expand when content opens, and a small press response on buttons and chips.
- New messages fade in.
- Motion follows the system setting "Remove animations". Nothing loops to hold attention.

## Under the hood

- Shared theme tokens keep their names, so every screen inherits the new palette.
- Components have a `pressScale` modifier, a reduced-motion aware `amcSpring`, `amcEnter` and `amcExit`.
- 3 new unit tests for the cleaning of system-note wording.

## Not changed in this release

- Settings, setup and onboarding screens take the new palette and type scale, but their layouts are unchanged.
- The wording of agent and engine messages is unchanged.

## Downloads

- `AMC-1.5.0-release.apk`: signed release build, with debugging disabled (when configured).
- `AMC-1.5.0-debug.apk`: development build with debugging enabled.
- Matching ZIP files contain the same APKs.
- `SHA256SUMS.txt` contains download checksums.
