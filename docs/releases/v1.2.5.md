# AMC v1.2.5

This release delivers comprehensive connection stability hardening, bridge background keep-alive improvements, full English localization, and expanded automated verification suites.

## Key Changes & Improvements

### Bridge Keep-Alive & Connection Stability
- **Detached Session Grace Window**: Termux bridge daemon now keeps active executions running for a 30-second grace window upon WebSocket disconnect (`DETACHED_SESSIONS`), preventing tasks from terminating during transient network interruptions or sleep cycles.
- **Android WakeLock Management**: `AgentForegroundService` acquires a `PARTIAL_WAKE_LOCK` with reference counting during active agent runs.
- **Termux Wake-Lock Cleanup**: Safe execution of `termux-wake-unlock` on daemon termination, signal trap (`SIGINT`/`SIGTERM`), or stop commands.
- **Exponential Backoff with Jitter**: Replaced rigid 1.5s reconnect delays with jittered exponential backoff (1s to 30s) to eliminate connection storms.
- **Instant Reconnection**: Integrated `ConnectivityManager.NetworkCallback` to trigger immediate reconnect when device network connectivity is restored.
- **WebSocket Heartbeat**: Optimized ping/pong timeouts (>= 10s) and removed redundant activity-level pings.
- **Resource Leak Fixes**: Eliminated unclosed pipe descriptor warnings and unhandled `ConnectionClosed` exceptions in unawaited asyncio tasks on Python 3.14.

### Full English Localization
- Complete audit and standardization of 100% of UI strings, Compose screens, setup wizards, settings dialogs, error banners, and log messages to English.

### Robustness & Engine Fixes
- **Room DB SQLite State Synchronization**: Resolved race condition between in-memory message state and SQLite database in `AutonomousAgentEngine.kt`.
- **Direct Boot Keystore Resiliency**: Added safe fallbacks for worker credential retrieval when device Keystore is temporarily locked after reboot.
- **Modernized Android APIs**: Migrated deprecated `LocalLifecycleOwner` and replaced Kotlin `Enum.values()` with `.entries`.
