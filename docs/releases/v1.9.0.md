# AMC v1.9.0 — Unattended runs and a complete audit trail

A task can now run to the end without anybody confirming anything — for hours, in the background, from a schedule, a notification trigger or Telegram, also across app and phone restarts. Instead of questions you get a complete, tamper-evident log and a report at the end.

## Unattended mode (opt-in)

- **Turn it on** by choosing **Unattended (Turbo)** and confirming the dialog once. It shows what will be allowed, what will be refused and what is never allowed; both answers are the same size.
- **Never asks, never parks:** a fixed rule per kind of action decides. Allowed actions run and are logged; refused ones are logged, the agent is told and keeps working on the rest.
- **Allowed by default:** deleting files, stopping processes, installing packages, camera and microphone, location, system settings (except security), operating apps, notifications, sending messages, reading private data.
- **Refused by default, you can allow them:** payments, calls, accounts and logins, store installs.
- **Never allowed:** catastrophic shell targets, banking/password/authenticator apps, Android security settings, AMC itself and its bridge token.
- **Prompt-injection guard:** a web page, file, screen or notification cannot plant memory entries, schedules, triggers or skills, and cannot unlock refused actions.
- **Limits and emergency stop:** optional maximum duration, screen actions and messages per run; Stop in the chat, the notification, the new Quick Settings tile, the phone-control banner or `/stop` in Telegram stops every unattended run.
- **Run report** at the end of every unattended run (notification and Telegram), optional daily summary.
- Without the opt-in, Turbo and every other mode behave exactly as before.

## Audit log

- Every tool call is logged with trigger, redacted arguments, decision, rule, reason, result, duration and exit code.
- SHA-256 hash chain, verified in the app; the agent cannot read or change it.
- Timeline per run with filters, JSONL export, Markdown sharing, retention 30/90/365 days. Existing command logs were carried over.

## Long runs

- Older steps are summarized together with the plan instead of being dropped; the task stays pinned.
- Unattended runs end with an explicit status (done, partly done, blocked); questions are recorded and decided instead of waiting.
- Chat tasks keep working when you close the app and continue after a restart or reboot; Telegram continues an interrupted message and continues tasks that ran out of steps (up to three rounds).
- Background jobs for long processes (`job_start`/`job_status`/`job_stop`), large files and pages in windows, `edit_file`.
- Reconnects no longer run a command twice; the working directory survives reconnects.
- Schedules can wait for Wi-Fi, charging or a healthy battery; `list_runs` shows past runs.
- The agent learns one lesson from a failed unattended task; lessons never push your facts out of memory.
- Up to three sub-agents work side by side.
- The wake lock is held only while an agent works.

## Chat and Android

- Replies are formatted (headings, lists, links, code) with a **Copy code** button on every code block.
- Press and hold: **Edit and send**, **Read aloud**.
- **Share to AMC** from any app (links, text, photos) fills the chat input.
- Launcher shortcuts **New task** and **Stop agents**, Quick Settings tile **Stop AMC agents**.
- **Agent runs** overview: what works now (with Stop) and recent runs with status, report and chat.

## Fixes

Twelve problems found in a whole-app review were fixed, among them: batch screen actions now respect your own block list; the bridge token can no longer be read or changed through the shell; Gemini replies cut off mid-stream are retried and the Gemini key is no longer part of the URL; stopping the agent no longer interrupts your own command in the Terminal tab; removed custom rules stop working at once; the selected tab survives rotation; `web_fetch` works with `http://` links; unpairing Telegram in the app stops that account's running task; a bridge restart is noticed at once instead of after 25 seconds. Details: `docs/AMC-Autonomie-Review.md` (findings #29–#40).

## Update the bridge

The Termux bridge has new commands (background jobs, reconnect without double runs). Run the installer once more, or tap **Update bridge** when the app asks.

## Not checked on a device

This release was built and tested with unit, Robolectric/Compose and end-to-end tests, including a simulated unattended task with more than 60 steps, a bridge restart and an app restart. Unattended runs with real apps, the share sheet, launcher shortcuts, the Quick Settings tile and text-to-speech were not exercised on a real phone. Please report anything that does not work as described.
